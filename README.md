# Java Banking System

A beginner-friendly Banking System project built using **Java fundamentals**. This project is being developed step by step to improve my understanding of Java programming and object-oriented concepts.

## About the Project

The goal is to build a simple console-based Banking System where users can create accounts, perform banking transactions, and view account details.

## Planned Features

- Account creation
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Menu-driven interface
- Input validation

## Technologies Used

- Java
- VS Code
- Git and GitHub

## Concepts I'm Practicing

- Classes and Objects

## Learning Goal

Build this project incrementally, practice Java fundamentals, and learn how multiple classes work together in a real-world-style application.
